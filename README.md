# Sudoku Clash

A modern, interactive web-based Sudoku game with multiple difficulty levels and competitive features.

## Features

- Multiple difficulty levels (Easy, Medium, Hard)
- Interactive game board with intuitive controls
- Real-time validation
- Timer to track your solving speed
- Clean and responsive design
- Hint system
- Undo/Redo functionality

## How to Play

1. Open `index.html` in your web browser
2. Select a difficulty level
3. Click on a cell and use number keys (1-9) or on-screen buttons to fill in numbers
4. Use hints if you get stuck
5. Complete the puzzle to win!

## Game Rules

- Fill the 9x9 grid with digits 1-9
- Each row must contain all digits 1-9 without repetition
- Each column must contain all digits 1-9 without repetition
- Each 3x3 box must contain all digits 1-9 without repetition

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Simply open `index.html` in any modern web browser. No installation or build process required!
